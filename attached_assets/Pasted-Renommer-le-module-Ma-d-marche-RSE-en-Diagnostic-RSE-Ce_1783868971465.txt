Renommer le module **"Ma démarche RSE"** en **"Diagnostic RSE"**.

Ce module devient le véritable tableau de bord de maturité RSE de l'entreprise et constitue le cœur du SaaS Cocci.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
DESIGN

Je souhaite moderniser complètement l'interface.

Supprimer autant que possible les grands encadrés bleus actuellement présents dans le module.

Privilégier une interface beaucoup plus épurée :

• fond blanc ou gris très clair (#F8F9FA)
• cartes discrètes
• coins arrondis
• ombres très légères
• beaucoup d'espaces entre les éléments
• très peu de bordures
• typographie moderne
• interface aérée

Les donuts doivent devenir l'élément principal de la page.

Le regard doit immédiatement être attiré par les scores.

Les couleurs doivent uniquement servir à mettre en valeur :

• les donuts
• les badges
• les indicateurs
• les boutons

Les sections doivent être séparées principalement par des espaces et non par de gros cadres.

L'ensemble doit donner l'impression d'un logiciel SaaS haut de gamme.

Le Diagnostic RSE doit exploiter automatiquement les données déjà présentes dans les autres modules.

Lorsque des informations existent déjà, elles doivent préremplir ou suggérer certaines réponses.

Le Diagnostic RSE doit notamment utiliser :

• Capital humain

• Baromètre social

• Bilan carbone

• Parties prenantes

• Plan d'action

• Mes actions

• Numérique responsable

• Documents

• tout futur module Cocci

L'utilisateur ne doit jamais avoir à saisir deux fois la même information.

OBJECTIF
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Le Diagnostic RSE doit devenir le véritable cockpit de pilotage de la démarche RSE.

En quelques secondes, l'utilisateur doit comprendre :

• son niveau global de maturité ;

• ses points forts ;

• ses points faibles ;

• les catégories à améliorer en priorité ;

• sa progression dans le temps ;

• son niveau de complétude.

L'interface doit être élégante, moderne, très visuelle, intuitive, responsive et donner envie d'améliorer continuellement sa maturité RSE.
