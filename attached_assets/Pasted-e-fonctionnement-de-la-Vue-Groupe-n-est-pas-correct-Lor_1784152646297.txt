PRINCIPE GÉNÉRAL
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Dans tous les modules de Cocci, lorsque l'utilisateur sélectionne "Vue Groupe", les données affichées doivent être automatiquement récupérées à partir de l'ensemble des filiales.

Le groupe ne possède plus de données propres.

Il affiche uniquement une consolidation des données des filiales.

Cette règle doit s'appliquer à tous les modules actuels et futurs.

• Clients

La Vue Groupe doit afficher :

• Fournisseurs

Lieux (...)

Les connexions doivent également être consolidées.

L'interface graphique doit rester strictement identique à celle d'une filiale.

La seule différence est la source des données.

RÈGLE DE CONSOLIDATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Pour tous les modules de Cocci :

Si l'utilisateur consulte une filiale :

→ afficher uniquement les données de cette filiale.

Si l'utilisateur consulte la Vue Groupe :

→ afficher automatiquement la consolidation de toutes les filiales.

Aucune donnée ne doit être ressaisie au niveau du groupe.

Toutes les modifications sont réalisées uniquement dans les filiales.

Le groupe est une vue dynamique.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
OBJECTIF
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

L'utilisateur doit avoir exactement la même expérience visuelle entre une filiale et la Vue Groupe.

Les cartes, tableaux, graphiques, onglets, compteurs et synthèses doivent être identiques.

Seule la source des données change.

L'architecture doit être pensée pour que cette règle soit automatiquement applicable à tous les modules de Cocci (Diagnostic RSE, Parties prenantes, Dépendances, Matrice de matérialité, Achats & Fournisseurs, Bilan carbone, Capital humain, Plan d'action, etc.) sans avoir à redévelopper chaque module individuellement.
