1. PROBLÈME DE ZOOM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Lorsque l'utilisateur zoome ou dézoome, les colonnes de fond (AMONT / IN SITU / AVAL) restent fixes alors que les éléments React Flow se déplacent.

Le fond, les séparateurs et les zones colorées doivent faire partie du même canvas que les nœuds.

Le zoom et le déplacement doivent donc agir simultanément sur :

• les éléments
• les connexions
• les colonnes AMONT
• la colonne IN SITU
• la colonne AVAL
• les séparateurs

L'ensemble doit rester parfaitement aligné à tous les niveaux de zoom.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
2. SUPPRIMER LES ÉTIQUETTES DES FILIALES

Supprimer complètement les encarts :

"Martin Industrie"

"Martin Transport"

etc.

Ils alourdissent énormément la lecture.

Les cartographies doivent être différenciées uniquement par leur position verticale.

Créer automatiquement une liaison verticale entre :

Maison mère / Siège social

↓

Toutes les agences des filiales.

Agence Montpellier

│

Agence Lyon

│

Siège social

Agence Marseille

Agence Toulouse

Toutes les autres connexions restent créées manuellement par l'utilisateur.
